# Вавилонская библиотека

Курсовой проект на FastAPI, SQLAlchemy и SQLite. Читатели публикуют экземпляры, указывают желаемые книги и предлагают обмен. Раздел «Мои обмены» подбирает взаимные предложения в одном городе по названиям книг. После принятия предложения обе стороны подтверждают передачу. В паспорте экземпляра сохраняются дата и города передачи.

## Локальный запуск

Запустите `start.cmd` из папки проекта. Сайт открывается на http://127.0.0.1:8010, Swagger UI — на http://127.0.0.1:8010/docs. При первом запуске база создаётся автоматически.

Для демонстрационных аккаунтов запустите `python demo_accounts.py`. Созданные локальные пароли сохраняются в demo-access.txt. База, пароли и ключ подписи JWT исключены из Git. QR-код использует адрес, по которому открыт сайт. Для сканирования с другого устройства необходим доступный ему адрес.

Географические данные: Natural Earth, набор world.geo.json.
